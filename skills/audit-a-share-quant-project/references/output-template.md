# Output Template

Use these templates to keep recurring maintenance responses consistent.

## Full Audit

1. `Findings`
   Start with `P0` and `P1` only.
   For each:
   severity
   file or flow
   why it matters
   concrete fix

2. `Core Improvements`
   Show only the highest-signal snippets or summarize the implemented patch.

3. `Maintenance Summary`
   Include:
   what improved in this pass
   what still needs attention
   what should be audited next

4. `Market Suggestion`
   Tie recommendations to current A-share regime, liquidity, crowding, and execution feasibility.

## Recurring Maintenance Update

Use this shorter shape when the repo is already under active maintenance:

- `This pass improved`
- `Open risks`
- `Next target`

Keep it short. Avoid repeating old resolved findings unless behavior changed.
